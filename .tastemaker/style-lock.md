# Night Arcade

Основание: утверждённое ТЗ, пять просмотренных изображений в references.
Продукт: портретная игровая оболочка, не лендинг и не dashboard.
Палитра: #080B10 / #0E131B / #141B25 / #1B2532 / #344154;
текст #E7EDF5, вторичный #96A6B8; действие #C5F542, XP #30C6FF,
деньги #FFCA3A, опасность #FF6575, казино #8B78FF.
Текст на акцентных заливках — #080B10, на тёмных — светлый.
Сетка 4px, прямые края, ступенчатые уголки, внутренние отступы 12–20px.
Шрифт: локальный лицензированный пиксельный с кириллицей + читаемый системный для длинных правил.
Графика: оригинальные пиксельные персонажи и тайлы; pixelfx MIT для эффектов.
Движение: 100–180ms для UI, игровые анимации по событиям. Reduced motion.
Запреты: коричневые панели, glassmorphism, emoji вместо спрайтов, чужие персонажи.

## Контраст (проверен скриптом)
- E7EDF5 / 080B10: 16.73:1; E7EDF5 / 141B25: 14.70:1.
- 080B10 / C5F542: 15.50:1; 080B10 / FFCA3A: 12.91:1.
- Светлый текст на лаймовой/жёлтой заливке запрещён; используется 080B10.
- 344154 / 141B25: 1.67:1, только декоративные рамки. Состояние обозначается дополнительно текстом/формой/ярким акцентом; focus — cyan.
