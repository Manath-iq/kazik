# STREET LEGENDS

Ночная пиксельная Telegram Mini App: вылазки с автоатакой, виртуальное казино, банды и простой город. React + Phaser 3.90 + Hono + Cloudflare D1.

**Доллары нельзя купить, вывести или передать. Нет денежных призов.** Не казино на настоящие деньги. После MVP добавлена отдельно подтверждённая владельцем добровольная поддержка разработки за Stars — без игровых наград или преимуществ. [Экономика и платёжный контракт](docs/STARS.md).

## Быстрый локальный запуск

Node.js 22.12+ (проверено на Node 25), npm. Весь код — в этой папке, копировать проект не нужно.

```bash
npm ci
npm run db:migrate:local
npm run dev
```

Открыть **http://127.0.0.1:5174**. API: `127.0.0.1:8793` — порт 8787 намеренно не занимаем, он может использоваться другим проектом.

Локальный вход показывает `LOCAL · DEV MODE`, использует настоящую локальную D1, начальный баланс **0**. Заработать можно на вылазке или работе. Перезапуск dev-сервера сохраняет БД в `apps/api/.wrangler/state/`. Не удаляйте её ради обычного запуска.

## Что реализовано и что ещё требуется

- Игровой цикл: движение (WASD/стрелки/джойстик), автоатака, три противника, босс, добыча, XP, десять улучшений, пауза, результаты и серверная выплата.
- Три серверные казино-игры с историей, ограниченными ставками, восстановлением активного раунда.
- Банды: создание/приглашение/вступление/выход/исключение, топ-10 вкладов, сезоны, накопительный XP.
- Город: работы, бизнесы с 6-часовым лимитом, машины/жильё без боевых бонусов, профиль и ledger.
- Telegram HMAC, короткая серверная сессия, webhook-команды; тестовый бот/HTTPS подключены: [открыть](https://t.me/kaziktesttg_bot?start=play).
- Автоматический fullscreen в Telegram 8.0+, fallback expand и оба вида safe area. Нижняя игровая подсказка убрана; canvas занимает оставшееся место до системного safe area.
- Footprints машин, заборов, баков и фонарей; обход для врагов, swept-попадания снарядов. Магнит захватывает добычу и догоняет героя на ходу.
- Stars 25/100/250: нативный invoice, серверный pre-checkout, успешные платежи/возвраты, собственная история, явное согласие и /paysupport. Приём на тестовом боте **реальный**, не sandbox.
- 22 PNG из ChatGPT подключены: [статус](docs/art/ASSET_STATUS.md). Фон/предметы/иконки готовы к предварительному использованию; пять атласов персонажей ещё требуют полировки анимаций. Финальное визуальное качество не объявляется принятым. При отсутствующих файлах в local preview показываются явные технические маркеры.

Подробный фактический статус — [PROGRESS.md](PROGRESS.md).

## Проверки

```bash
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm audit
```

`npm test` использует изолированный workerd + настоящую SQLite D1 через Miniflare, без production-доступа. E2E — локальный браузер; он создаёт реальные локальные игровые операции, не трогает удалённую БД.

`npm run build` собирает веб и выполняет **dry-run**, а не публикацию API. Большой отдельный lazy chunk Phaser ожидаем: он загружается при старте вылазки, не нужен для чтения профиля/города.

## Бесплатное размещение

Рекомендуемый вариант: **один Worker со Static Assets + одна D1 + GitHub для исходников**. GitHub Pages не нужен для работы сервера, но поддерживается как альтернативный frontend.

На Workers Free по документации, проверенной 04.11.2026:
- 100 000 динамических запросов/день, 10 ms CPU на запрос;
- статические assets бесплатны и не расходуют этот лимит;
- D1: 5 млн прочитанных и 100 000 записанных строк/день, 5 GB суммарно, максимум 500 MB на одну бесплатную БД;
- индексы тоже расходуют записи. Бесплатность не означает неограниченную аудиторию.

Контрольные события — раз в 10 секунд, ракетка опрашивается раз в 1,5 секунды только пока идёт раунд и страница видима. Результаты/история ограничены LIMIT, не весь массив. Нет WebSocket-серверов, VPS, платной аналитики, R2, AI API, Redis или покупных ассетов. Не переключать аккаунт на Paid автоматически.

При исчерпании Free-квоты возможны отказы API до сброса лимита, а не обещание бесперебойного обслуживания. Для первого закрытого теста подходит; точная вместимость проверяется по реальным метрикам, не выдуманной цифре игроков.

## Безопасность и ограничения

Баланс меняется только вставкой уникальной проводки в `wallet_ledger`; trigger обновляет кошелёк, CHECK запрещает минус. В D1 batch все связанные SQL-команды откатываются вместе. CAS по версии/статусу не позволяет двум запросам одновременно завершить одну выплату. Предварительное чтение баланса само по себе не используется как защита.

Сервер выдаёт run_id/seed и проверяет последовательность checkpoints, фактическое время, пределы спавна, перемещения, XP и дохода. **Это НЕ полноценный античит**: клиентская симуляция может быть подделана в допустимых пределах. Для серьёзного соревновательного запуска нужны replay/серверная проверка лучших результатов или авторитетная симуляция. Пометка `guarded` означает только прохождение базовых проверок; аномалии исключаются из рейтинга и выплаты.

Секреты не хранить в localStorage, Git, логах и `.env` Vite. Существующий тестовый Bot Token оставлен по прямому решению владельца; это не подтверждение его пригодности для публичного платёжного проекта. В `.dev.vars` только локальные секреты, файл игнорируется Git. DEV auth существует в отдельном `src/local.ts`, production `src/index.ts` его не импортирует. Не публиковать local-конфиг и не открывать dev-сервер в интернет.

Перед публичным запуском отдельно проверить актуальные правила Telegram, возрастные/региональные ограничения и применимое право даже для виртуального казино. Приложение не делает вывод о юридической допустимости.
