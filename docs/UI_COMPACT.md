# Игровая оболочка без лишнего текста — 05.11.2026

Пользователь отверг длинные скроллящиеся экраны, баннеры, слоганы и технические пояснения. Подтвердил «Сразу в код»: основные портретные экраны без вертикального скролла, длинные списки и подробности — отдельно.

Режим: переработка композиции с сохранением Night Arcade, оригинальной графики, четырёх вкладок и всей серверной логики. Experience / Operate; variance 4, motion 2, copy density 2, asset dependence 8, brand fidelity 10. Телефон читается с близкого расстояния: обычные подписи 12–16px, действия ≥44px. Не уменьшать весь интерфейс масштабированием.

## Состав
- Вылазка: большая оригинальная сцена с героем, рекорд и запуск; помощь/топ по кнопке. Никаких абзацев, версии, обещаний или второй рекламной шапки.
- Казино: переключение игры, игровое поле, выбор ставки/цели и действие. Правила и история — отдельные native dialog. Одна короткая пометка про игровую валюту остаётся.
- Город: три компактные позиции в категории; текущая смена заменяет недоступный список работ. Покупка подтверждается отдельно. Без баннеров/слоганов.
- Банда: эмблема, имя, недельные очки/XP, создать/вступить или пригласить/состав. Формы, участники и история отдельно.
- Профиль: вкладки досье/коллекция/настройки/операции вместо одной длинной страницы. Stars/условия/возвраты сохраняются, не смешиваются с игровыми долларами.
- Результат: волна, время, убийства, подтверждённая добыча и повтор. Тексты ошибок и проверок сохраняются, рекламные абзацы удалены.

## Контракты
Не менять экономику ×1000, полные выплаты, Stars, API/D1, auth, Phaser-коллизии/магнит/пулы. Не терять элементы через overflow:hidden: сначала сократить и разделить состав; длинные модальные списки постраничные, юридические тексты могут прокручиваться. Нативные dialog сохраняют Escape/focus; Telegram Back закрывает верхнее окно.

Палитра/типографика — существующий style-lock, сетка 4px, отступы 8/12/16, прямые пиксельные края, спокойные press states 120ms. Новые фото/непиксельные иллюстрации/библиотеки анимаций не нужны. Утилитарные значки Lucide ISC/MIT; игровая графика прежняя.

Проверки перед выпуском: обязательные lint/typecheck/test/build; короткий визуальный просмотр вместо повторных длинных игровых/нагрузочных прогонов по предыдущей просьбе пользователя.
