## Атласы для предварительного подключения — needs-fix

`player.png`, `enemy-thug.png`, `enemy-runner.png`, `enemy-brute.png`: 192×96, frameWidth/frameHeight 48. `boss.png`: 256×128, кадр 64×64. Все имеют alpha, 4 колонки × 2 строки, без spacing/margin. Индексы: idle 0–1, run 2–5, hit 6, down 7. Начальный ориентир частоты: idle 2 fps, run 7 fps; это рекомендация, не результат теста в игре.

Файлы технически валидны, но анимации не считать окончательно готовыми: небольшое дрожание idle, изменения силуэта/длины шага, несовершенное чередование ног. Можно подключать кадр 0 как статичный образ; движение сначала проверить в Phaser, затем отполировать. Исправленный player-v02 сохраняет пистолет в одной руке. Повторять один кадр восемь раз как замену анимации не нужно.

## Особенности

- `pixelArt: true`, nearest filtering, сглаживание отключить. Не растягивать по независимым осям.
- Персонажи: центр x24/y42 у ступней; босс x32/y57. Начальный origin `(0.5, 43/48)` / босс `(0.5, 58/64)`; корректность столкновений должен проверить игровой агент.
- Тени персонажей рисует игра, в PNG их нет.
- Фонарь: основание x24, нижний непрозрачный пиксель y61; origin `(0.5, 62/64)`.
- Ограда: соседние секции ставить с шагом 58px при масштабе 1, чтобы столбы перекрывались. Прямое повторение с шагом 64 оставляет промежутки.
- `prop-neon.png` — вертикальная вывеска с прозрачными полями в контрактном холсте 64×48. Она выделена из исходника с лишним фасадом; размер контракта сохранён.
- Асфальт/тротуар непрозрачны, разметка — отдельный overlay. Повтор 3×3 просмотрен; повторяемость узора есть.
- Лобби статично, текст и UI не запечены. Вся графика оригинально сгенерирована; референсные скриншоты в runtime не копировались.

## Воспроизводимость и проверки

`python3 tools/art/prepare.py` — подготовка из сохранённых raw, сборка PNG/превью/GIF и manifest. Нужен установленный Pillow. Если raw уже в проекте, доступ к исходному каталогу Codex не нужен. V01 не удалены, выбранные герой/тротуар используют V02.

Происхождение, SHA256, операции и ограничения: `ASSET_PROVENANCE.json`; статус и логи: `ASSET_STATUS.md`. Название модели неизвестно и не выдумано. Lint, typecheck, 24 теста и build прошли. Игровое воспроизведение и телефон не проверены. Блокеров инструмента генерации нет; остаётся полировка пяти анимаций.
