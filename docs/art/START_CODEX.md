# Задание для отдельной сессии Codex: графика STREET LEGENDS

Скопируй в новую сессию Codex этот текст:

```text
Работай в существующем проекте /Users/manath/myAI/kazik.
Твоя задача — сгенерировать через штатную генерацию изображений ChatGPT/Codex оригинальную игровую графику для STREET LEGENDS и подготовить её для Phaser. Не разрабатывай приложение: другой агент параллельно пишет код.

Сначала прочитай:
1. AGENTS.md в корне и STREET_LEGENDS_CODEX_PACK/AGENTS.md.
2. STREET_LEGENDS_CODEX_PACK/STREET_LEGENDS_MVP.md — особенно разделы 2, 3, 4.
3. docs/art/ART_DIRECTION.md.
4. docs/art/ASSET_CONTRACT.md.
5. docs/art/PROMPTS.md.
6. docs/art/ASSET_STATUS.md.
Посмотри пять изображений в STREET_LEGENDS_CODEX_PACK/references. Это только референсы; не копируй их персонажей, композиции, UI и коричневую палитру.

Начни с P01 (лобби), P02 (герой), P03 (гопник). Покажи результаты и проверь, что они образуют один визуальный набор. Затем выполни остальные P04–P11. Если пользователь не отвечает, продолжай в стиле арт-брифа; не объявляй выбор утверждённым пользователем.

Обязательно используй доступный штатный image-generation инструмент. Если его нет или кончился лимит подписки — честно останови именно генерацию и укажи блокер. Не подменяй её программно нарисованными фигурами, чужими картинками, платным API или выдуманными результатами. Не покупай кредиты/подписки. Никаких скрытых API, извлечения cookie и ключей. Авторизацию в веб-интерфейсе проходит пользователь.

Записывать можно ТОЛЬКО:
- art/source/** — оригинальные результаты генерации;
- art/review/** — контактные листы и превью;
- apps/web/public/assets/generated/** — подготовленные runtime PNG;
- tools/art/** — скрипты нормализации, проверки и нарезки;
- docs/art/ASSET_STATUS.md — ход работы и замечания;
- docs/art/ASSET_PROVENANCE.json — происхождение файлов;
- docs/art/INTEGRATION_NOTES.md — итог и особенности подключения.

Не меняй исходники React/Phaser/API, package.json, lockfile, конфиги, миграции, существующие инструкции и промпты. Не меняй Git remotes; не делай push, deploy или reset. Не запускай второго агента. В проекте параллельно работает другой агент — не удаляй и не перезаписывай незнакомые изменения.

Сохраняй raw-источники отдельно. В runtime отдавай только PNG согласно ASSET_CONTRACT.md; референсы туда не копировать. У спрайтов и предметов нужна настоящая alpha-прозрачность, не нарисованная шахматная клетка. Удалять однотонный фон можно скриптом; не вырезай персонажу чёрные детали. Если точная сетка кадров у генератора не получается, генерируй позы отдельно и собирай атлас скриптом. Никогда не растягивай персонажа для подгонки. Сгенерированные листы не считать автоматически пригодными для Phaser без проверки каждого кадра.

Проверяй глазами изображения на реальном игровом размере, а скриптом — размеры, alpha, число кадров, пустые поля и выход за границы. Для анимаций собери увеличенный контактный лист и по возможности GIF. Сохрани manifest/provenance с реальными данными; название модели указывай только если оно известно. Не утверждай, что проверена анимация в игре, если игру не запускал.

По завершении дай список готовых runtime-файлов, проблемных файлов и блокеров; сообщи основному агенту, что можно подключать. Не называй весь MVP готовым: твоя область — только графика.
```

## Как запустить

Открыть новую сессию Codex **в той же папке**, без копии проекта. Вставить блок выше. Убедиться, что в выбранной среде доступна штатная генерация изображений.

Доступный в текущей OpenCode-сессии браузер сам по себе не означает, что Codex получит доступ к ChatGPT-подписке. Если инструмент генерации отсутствует, сессия должна сообщить об этом, а не обещать генерацию.
