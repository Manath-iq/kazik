# Pixelfx — обратная связь Night Arcade

MIT-источник: https://github.com/patch-gg/pixelfx, commit `a84159688af3ca37a4be05a0d422b94451b2e24e`. Авторские уведомления сохранены в `vendor/pixelfx/NOTICE.md` и `LICENSE`, новые файлы зафиксированы SHA-256 в `SOURCES.json`. Gallery-шрифт и stock-персонажи не используются. Оригинальная игровая графика не заменяется.

- Выстрел: маленькая направленная вспышка и дым.
- Обычный удар / крит: разные всплески, крит также подписан текстом.
- Препятствие: искры в реальной точке swept collision, пуля не проходит сквозь объект.
- Смерть: короткий серый poof, для босса немного крупнее.
- XP / деньги / лечение: голубой / золотой / коралловый подбор; HP подписан числом.
- Выбор улучшения: зелёный эффект уровня вокруг нашего героя. Back/front находятся по разные стороны спрайта, следуют за героем.
- Результат и город: разовый эффект только после серверного подтверждения. Ошибки, подозрительные забеги, Stars и казино не получают праздничных эффектов.

`npm run assets:fx` — полный offline-экспорт прямоугольных PNG без растягивания: native pixels, прозрачные поля, точные pivot, полная исходная длительность и явный playbackRate. Оба слоя сохранены; UI использует те же PNG. Все атласы ≤2048 px, текущий набор около 1,17 MiB сжатый / 29,8 MiB RGBA. Live-симулятор pixelfx в приложение не импортируется.

Phaser заранее создаёт **16** спрайтов на всю сцену, включая оба слоя уровня. Детерминированный timeline без RNG, callback-очередей и новых GameObjects в бою. Есть общий резерв, приоритеты, cooldown, per-event caps и offscreen culling. Пауза замораживает clock; скрытие, выключение и shutdown освобождают эффекты. Не меняются RNG боя, урон, коллизии и экономика.

Настройка «Пиксельные эффекты» в профиле/паузе сохраняется локально. Системный reduced motion подавляет декоративные вспышки независимо от настройки; HP, XP, деньги и текстовая обратная связь сохраняются.

Локальные review routes, без API и наград: `/__game-review?case=effects|feedback|wall|fx-stress`. В production они вырезаны. Контактный лист: `node tools/fx/preview.mjs` → `.local/fx-contact.png`. Дополнительный benchmark доступен как инструмент, но по просьбе пользователя длинный прогон перед этой выкладкой **не запускался**.

Проверены 7 unit/asset tests и 4 E2E сценария эффектов (включая 72 врага, fixed pool, реальные combat/pickup paths, reduced motion, паузу и отложенный/ошибочный ответ покупки). Это не доказательство FPS на физическом телефоне; живую проверку Telegram выполняет пользователь.
